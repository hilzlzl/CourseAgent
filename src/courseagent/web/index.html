自主作业 Agent

提交要求后自动搜题、改编、检查、换题与补齐。默认只在本地生成并导出作业；配置交付目标并关闭本地模式后，才会操作平台未发布草稿。

本地生成与可选交付

Agent 根据缺口、已有素材和失败记录决定改编、补搜或修复，不因固定3轮而停止；总预算为60次模型调用，15分钟后不再发起模型请求。编程题自动补齐平台用例、设置公开或隐藏，并在保存后回读核对。尚无独立计算验证的预期输出会明确提示，不阻断未发布草稿交付。

手动工作台（可选，点击展开）

手动调整作业

预计完成时间仅作参考，不影响选题和导入，也不是头歌考试限时。难度要求由教师核对，不按默认难度筛选，不逐题调用模型评估。默认按文件题库规则筛选；配置模型后可辅助理解要求和选题。网络模式优先寻找已有原题，资料用于明确教学范围；缺题时只补对应题型，保留已读网页和合格题。文件模式支持提取 Word、PDF 中的原题；配套答案直接采用，只检查提取、匹配和格式。

教学目标（可选，留空自动规划）

每行填写：目标名称 | 题干关键词（逗号分隔），最多12条。例如：遍历与序列分析 | 先序,中序,后序,遍历。用于按考点搜题和分散选题；下次推荐时生效，不修改当前已审核题目。自动分配为软目标，缺少匹配时保留题量并提示。

补充指定网页（可选）

可搜相关原题，也可搜知识讲解并据此出选择、判断、填空或应用题。改编题作为新题单独核验，不沿用原题答案或评测结论；默认关闭。无答案的网络原题可补答后核验，资料配套答案不重新裁决。

课程知识点表与本地识别

下列是为现有数据结构资料准备的可修改起始表，不是自动生成的完整课程目录。每行填写：分组 | 知识点 | 关键词（用逗号分隔）。识别只读取题干和原有知识点，不用答案、选项或文件名推断，不调用模型。

查看或修改知识点表

应用只更新当前预览，点击“保存进度”后才保留。修改题干、原有知识点或词表后，旧标签确认需重新核对。规则线索不等于已确认覆盖；没有标签的题仍可选用。

整卷质量检查

检查当前已选题，定位重复考点、答案提示、格式与条件问题。检查结果是审核建议，不自动替换题目。

当前作业 · 逐题审核

逐题核对并勾选确认后，点击“完成审核”。保存进度后，重新打开页面可继续审核当前作业。

历史方案 / 找回旧方案

需要保留另一套方案时，先填写名称并另存。恢复仅加载预览，保存后才替换当前作业。

在线考试 · 编程题审核

在这里审核完整题目、输入输出、语言、初始代码、评测用例及输出依据，参考代码可选。支持自然语言编程题搜题、录入、导入题目文件及混合 Excel 导出。代码仅展示，不在本机执行。
